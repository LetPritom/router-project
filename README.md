# Hero-app

# Description
App Manager Dashboard is a responsive React app where users can browse, install, and uninstall apps. Installed apps are saved in localStorage, so data stays even after reload. It features dynamic routing, toast notifications, charts, and a clean UI built with Tailwind CSS and DaisyUI

##  Features

- Dynamic routing with React Router
- Responsive layout using Tailwind CSS
- Prebuilt UI components via DaisyUI
- Interactive charts with Recharts
- Toast notifications for user feedback
- Clean iconography using Lucide
- Dynamic Routing
# Responsive
 *Responsive Design*  Works smoothly across desktop, tablet, and mobile

# Installation function
*App Installation System* - Click app card to view installation details

# Uninstall function

 *Uninstall Functionality* - Removes app from UI and localStorage

# Charts details
*Charts & Stats* - Visual Ratings insights using Recharts

# Alert For Using toastify
*Toast Alerts* - Feedback for install/uninstall actions

# Dynamic Routing
 *Dynamic Routing* - `/apps/:id` routes with fallback handling.
